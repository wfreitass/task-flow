# Shared

Componentes, diretivas, pipes e utilitários genéricos com reutilização comprovada.
Este código não importa features nem conhece conceitos de tarefas ou identidade.

Criar subpastas somente quando houver uma necessidade real. Componentes específicos
de tarefas ficam na apresentação da feature; Material pode ser importado diretamente
por cada componente standalone, sem wrappers antecipados.

Consulte a [arquitetura](../../../docs/ARQUITETURA.md).
