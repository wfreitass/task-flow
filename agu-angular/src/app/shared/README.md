# Shared

Componentes, diretivas, pipes e utilitários genéricos com reutilização comprovada.
Este código não importa features nem conhece conceitos de tarefas ou identidade.

`ui/` contém campos de formulário, select, ações de formulário, tabela genérica,
Kanban com jKanban, confirmação e ícones. São utilizados pelo painel e não importam
as features. Componentes específicos de tarefas ficam na apresentação da feature.

Contratos e exemplos de uso: [03 — Painel de tarefas](../../../docs/03-PAINEL-DE-TAREFAS.md).
Campos de senha e opções das ações de formulário:
[04 — Login com componentes de UI](../../../docs/04-LOGIN-COMPONENTES-UI.md).
