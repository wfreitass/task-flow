# Application — Tasks

Casos de uso em TypeScript puro, dependentes do domínio e de interfaces de
repositório recebidas no construtor. Não importar Angular, HTTP, infraestrutura,
componentes ou estado de interface.

`use-cases/` contém listagem, criação, edição, exclusão, movimentação e carregamento
de exemplos. As entradas usam TaskDetails do domínio. Nenhum caso de uso conhece
Angular, localStorage ou jKanban. Testes adiados nesta etapa a pedido do usuário.

Consulte a [arquitetura](../../../../../docs/01-ARQUITETURA.md).
